# Verify UI

Validate the relevant user journey with the vocabulary and simplicity rules in
`docs/UX.md`. Check empty, loading, error, published, and stop-sharing states
where applicable, including keyboard/accessibility behavior supported by the
chosen stack. Confirm technical concepts are absent from default UI. Report
reproducible findings and verification evidence; do not alter product behavior
outside the assigned task.
