# Implement Feature

Before editing, read the source-of-truth documents in `AGENTS.md`, confirm the
milestone and task acceptance criteria, and claim only the assigned files in
the assigned worktree. Implement no behavior outside the task scope.

Add the relevant tests from `docs/TESTING.md`, run the applicable checks plus
`./scripts/verify`, and report commands/results, changed files, security
invariants, risks, and commit SHA. Request independent review; do not self-
approve security or architecture-sensitive changes.
