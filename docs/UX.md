# UX Principles

## Default language
Use non-technical concepts.

Preferred user-facing vocabulary:
- Mis proyectos
- Nuevo proyecto
- Materiales
- Creaciones
- Vista previa
- Publicar
- Dejar de compartir
- Copiar enlace
- Mostrar QR

Avoid exposing in default UX:
- OpenCode
- Cloudflare
- API
- port
- tunnel
- runtime
- server
- DNS

## Main screens
### Projects
List local projects and clearly show Local vs Published state.

### Project
Chat + Materials + Creations + Preview + Publish/Stop sharing.

### Published state
Show public URL, copy action, QR, and Stop sharing.

## Closing app
If one or more projects are published, warn that public links will stop working.
