# Definition of Done Template

A task is complete only when:

- [ ] Scope and acceptance criteria are satisfied.
- [ ] Architecture boundaries are preserved.
- [ ] Relevant tests exist and pass.
- [ ] Format/lint/type checks pass.
- [ ] Security invariants are unaffected or explicitly tested.
- [ ] Documentation/ADR updated when behavior or architecture changed.
- [ ] Independent review completed when practical.
- [ ] `./scripts/verify` passes once implemented.
