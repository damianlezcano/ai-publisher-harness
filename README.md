# AI Publisher

Desktop application for non-technical users to create resources with AI locally and publish them temporarily to the Internet with one click.

## Product idea

Idea -> AI creation -> Preview -> Publish -> URL/QR -> Stop sharing.

OpenCode is the AI/agent engine. The desktop application owns projects, materials, creations, preview and publication. A single local HTTP publisher exposes all currently published projects through one Cloudflare Quick Tunnel.
